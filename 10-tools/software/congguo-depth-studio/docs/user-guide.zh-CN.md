# 葱果深度工坊使用说明

## 安装

当前正式使用路径只支持 Apple 芯片 Mac（macOS 13 或更高版本）。仓库只保存源码，不保存
App、发布 ZIP 和模型，因此仅克隆 Git 仓库不能直接获得可运行软件。

1. 向发布负责人获取带版本号的 `葱果深度工坊-v2.3.0-macOS-arm64.zip` 及 SHA-256。
2. 校验文件；例如：`shasum -a 256 葱果深度工坊-v2.3.0-macOS-arm64.zip`。
3. 解压 ZIP，将“葱果深度工坊.app”拖入当前用户的“应用程序”目录（`~/Applications`），
   或系统“应用程序”目录（`/Applications`）。
4. 双击启动。首次打开若被 macOS 阻止，按住 Control 点击 App，选择“打开”。

目前 GitHub Releases 中还没有公开安装包。拿不到发布 ZIP 时，请联系发布负责人；开发者可按
[`development.md`](development.md) 使用源码运行，但仍需要获准的 ONNX 模型。

## 使用方法

1. 打开“葱果深度工坊”。
2. 将视频拖入窗口，或点击“选择视频”。
3. 确认输入区已显示文件名、分辨率和时长。
4. 选择输出帧率，并决定是否保留原始音频。
5. 点击“开始提取深度”。
6. 完成后在“最近输出”中直接播放或定位文件。

## 重要说明

- 软件全程本地处理，视频不会上传。
- 无需 Codex、ChatGPT、API Key 或网络。
- 输出是单目相对深度视频，不是骨骼动作捕捉数据。
- 建议为处理临时文件预留至少原视频体积 3 倍的空间。

## macOS 首次打开

如果本地测试版被 macOS 阻止，请在 Finder 中按住 Control 点击 App，选择“打开”并再次确认。

## 卸载

退出软件后删除“葱果深度工坊.app”即可。软件不会在系统中另装模型或 Python 环境；最近输出
记录保存在 Qt 的用户设置中，删除 App 不会删除输入视频或已生成的深度视频。
