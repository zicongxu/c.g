# 葱果传媒协作空间

这里是葱果传媒的公司知识与协作入口。葱果传媒是一家 AI-native 的视频 AI 创业公司；这个空间既服务团队成员，也服务获得授权的 AI Agent。

## 从这里开始

- 不知道放哪里：先放入 [`00-inbox/`](00-inbox/README.md)，每周整理。
- 找公司背景与目标：进入 `01-company/`。
- 找产品需求与路线图：进入 `02-products/`。
- 找视频项目、创意与制作流程：进入 `03-studio/`。
- 找市场、用户、模型和实验研究：进入 `04-research/`。
- 找架构、决策、仓库和运维手册：进入 `05-engineering/`。
- 找增长、内容、销售与指标：进入 `06-growth/`。
- 找人事、财务、法务与行政：进入 `07-operations/`。
- 找跨部门长期知识：进入 `08-knowledge/`。
- 找 Agent、Skill、Prompt、Workflow 与评测：进入 `09-ai/`。
- 找 CLI、脚本、集成与软件清单：进入 `10-tools/`。
- 新建文档：从 [`90-templates/`](90-templates/README.md) 复制模板。
- 过期但需保留的内容：移动到 `99-archive/`，不要直接删除。

## 知识保存原则

1. **一个事实只有一个权威来源。** 其他地方使用链接，不复制粘贴；文档头部填写 `source_of_truth`。
2. **知识和工作流分开。** 稳定事实、决策和方法写入文档；临时任务进入项目管理工具；聊天记录不是知识库。
3. **原始材料与结论分开。** 访谈、会议、论文放 references/meetings；可执行结论进入 brief、spec、playbook 或 ADR，并链接原始证据。
4. **视频大文件外置。** 原片、模型权重、数据集和渲染产物放对象存储/NAS；本空间只保存清单、版本、许可、哈希和访问链接。
5. **AI 产出默认待验证。** 未经负责人确认的内容使用 `status: draft`，不得自动升级为公司事实。
6. **记录为什么。** 昂贵、长期或难逆转的决定写 ADR，不覆盖旧决定，用新 ADR 标记取代关系。
7. **可检索优先。** 文件名使用小写英文 `kebab-case`；正文可中文；标题、摘要、标签和负责人必须明确。
8. **敏感信息最小化。** 不提交密钥、个人隐私、客户原始数据。财务、法务、人事材料按权限放在受控系统，此处只留索引。

详细规则见 [`KNOWLEDGE.md`](KNOWLEDGE.md)，不同信息系统的存储边界见 [`STORAGE.md`](STORAGE.md)，Agent 行为约定见 [`AGENTS.md`](AGENTS.md)。

## 建议节奏

- 每周：清空 `00-inbox/`，处理失效链接和无人负责的草稿。
- 每月：产品、模型、工具与软件目录复核一次。
- 每季度：战略、指标口径、权限与归档复核一次。
- 项目结束：沉淀复盘与可复用资产，再将过程材料归档。
