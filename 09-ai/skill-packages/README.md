# Skill Packages

This directory stores raw, unreviewed, or distributable bundles that contain one or more Skills.

A Skill package is not automatically an installed or production-ready Skill. To install a package:

1. Inspect the archive without executing included scripts.
2. Review licenses, provenance, instructions, and executable files.
3. Extract each approved Skill to `09-ai/skills/<skill-name>/SKILL.md`.
4. Register each extracted Skill in `09-ai/skills/registry.yaml`.
5. Evaluate each Skill independently before setting it to `active`.

Register every retained package in `registry.yaml`.
