# Engineering

| Directory | Content |
|---|---|
| `architecture/` | Current system map, data flow, boundaries |
| `decisions/` | Numbered ADRs for costly or hard-to-reverse decisions |
| `standards/` | Code, API, security, data, release standards |
| `runbooks/` | Deploy, rollback, troubleshooting, operations |
| `incidents/` | Timeline, impact, root cause, corrective actions |
| `repositories/` | Repository, owner, environment, documentation entrypoints |

Keep implementation details in code repositories. Store cross-repository architecture, decisions, constraints, and operations here.
